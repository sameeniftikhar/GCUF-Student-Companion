# 🎓 GCUF Student Companion - All-in-One C++ Manager

Built in 1st Semester of BSSE at GCUF - My Star Project!

### Problem I Solved:
Every GCUF student juggles GPA, mess/transport budget, and assignments in different notes. I made ONE app for all.

### ✨ Sprint 1 Features (Live Now)
- **GPA Calculator:** Calculates percentage & grade
- **Budget Tracker:** Add daily expenses (Mess, Books) & view report
- **File Handling:** All expenses saved permanently in `budget.txt` (fstream)

### 🚀 Coming in Sprint 2
- Study Planner with Priority (High/Med/Low) + File Saving
- Search & Delete expense feature

### 🛠️ Tech Stack
**Language:** C++ | **Concepts:** Functions, Loops, File I/O (ofstream/ifstream), Modular Code
**Methodology:** Agile Sprints, Planned on Trello, Debugged with Claude Code (Anthropic Certified)

### ▶️ How to Run
g++ main.cpp -o companion
./companion
